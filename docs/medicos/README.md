# ASII - Variante medicos

Esta carpeta agrupa la evidencia del parcial independiente para el modulo de medicos, especialidades y disponibilidad.

## Entregables

- Fuente editable de diagramas.
- Razonamiento arquitectonico.
- Contrato API y evaluacion de frontera de microservicio.
- Guia de defensa de la primera evaluacion parcial.
- Evidencia de ejecucion local.
- Guia de datos ficticios.

## Archivos clave

- `diagramas/01-componentes.mmd`
- `diagramas/02-secuencia.mmd`
- `razonamiento-arquitectonico.md`
- `semana-05-api-y-microservicio.md`
- `semana-06-defensa-arquitectura.md`
- `paso-a-paso-entrega.md`
- `evidencia.md`

## Orden para completar la entrega

1. Leer `semana-05-api-y-microservicio.md` y completar el contrato API.
2. Crear el issue, la rama feature y el worktree del modulo.
3. Revisar los diagramas y relacionarlos con los endpoints.
4. Ejecutar la prueba del conflicto de horarios y guardar la evidencia.
5. Usar `semana-06-defensa-arquitectura.md` para preparar las 8 diapositivas.
6. Publicar la rama y abrir el Pull Request.
7. Registrar en Project Odoo los enlaces del repositorio, issue y PR.
